Privacy Policy

This policy covers the WealthSignals Pipeline application and the Google user data it accesses through the YouTube Data API and the YouTube Analytics API.

Who operates this

WealthSignals Pipeline is built and run by one individual as a personal content project. It is authorized against exactly one Google Account, the owner of the WealthSignals YouTube channel, and is not distributed to or used by anyone else. There is no public sign-up, no account creation, and no other users.

What data it accesses

When the authorized Google Account grants access, the application can:

  • Upload videos to the WealthSignals YouTube channel, and set each video's title, description, tags, and privacy status, via the YouTube Data API.
  • Read performance data for the WealthSignals channel, including views, watch time, and audience retention, via the YouTube Analytics API.

It does not request access to Gmail, Drive, Contacts, Calendar, or any other Google service, and it does not access any YouTube channel other than WealthSignals.

How the data is used

Channel and analytics data is used solely to operate the WealthSignals channel: publishing new videos on a schedule, and using past performance data to decide what topics to cover next. This data is never used for advertising, never sold, never shared with data brokers, and never shared with any third party except where strictly necessary to provide the service described above.

Video scripts are drafted with the help of a third-party AI text-generation API. That service receives only the topic and script text being written. It never receives Google Account data, credentials, or analytics figures.

This application's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

How access is stored and protected

The OAuth refresh token that grants this access is stored as an encrypted secret in GitHub Actions. It is never written into source code, never committed to a repository, and never exposed in logs or build output.

Data retention

The application retains only what it needs to operate: the OAuth token itself, and a small internal log of which video topics have already been covered, to avoid duplicate uploads. No personal data about viewers of the channel is collected or stored.

Revoking access

The account owner can disconnect this application at any time at myaccount.google.com/permissions. Once revoked, the application can no longer upload videos or read analytics for the channel, and any cached token becomes invalid.

Children's privacy

This application is an internal publishing tool operated by an adult channel owner. It does not knowingly collect data from children, and it does not interact with viewers or the general public in any way.

This policy may be updated as the pipeline changes. The date below reflects the current scopes and data use described here.
